## What this file does

Gives named application preferences to the JSON database: wallet/network settings, user metadata, scripts, backup options and RPC users.

## Follow the logic

1. Each scalar accessor delegates to JsonDB using a stable key. Defaults are computed when read: the welcome string includes the current version, hash rate defaults to one million, and Magic preferences use protocol constants.
2. Setters change in-memory JSON; this class does not automatically save a file after every preference change. The owner coordinates persistence.
3. Webhooks and permanent-contact lists are converted between Java lists and JSON arrays. RPC-user and uninstalled-app getters instead return JSON arrays directly, allowing aliases to observe mutation.
4. Uninstalled names are lowercased using the process locale and have literal ASCII spaces removed. Tabs and other whitespace remain. Adding removes one equal existing entry, then appends the normalized name; this is not a global deduplication pass over arbitrary loaded data.
5. setSlaveNode writes enabled before host. getPublicMDS gives the global command-line enable flag precedence over the stored false value.
6. Encrypted-seed methods merely store/retrieve MiniData. Encryption and authentication occur elsewhere; storing a field with that name does not encrypt it.

## How the translation is approached

Native methods retain the same keys/defaults and reuse JsonDB, MiniUtil list conversions and Java-compatible locale-sensitive lowercasing. Shared JSON-array ownership preserves important aliases; optional strings support null parameters, while UTF-16 webhook adapters handle strings that ordinary UTF-8 cannot represent exactly.

## What the tests tell us

The [preferences oracle](../../../../../../../support/PrefsOracle.java), [native harness](../../../../../../../support/prefs.cpp) and [driver](../../../../../../../tools/prefs_differential.py) enumerate all declared accessors, apply typed/null samples, inspect resulting JSON/wire data, exercise array aliases and malformed reads, and test names under English, Turkish, Azerbaijani, Lithuanian and Greek locales. The inspected [report](../../../../../../../build/prefs-differential-results.json) has 1,130/1,130 matching cases; that total includes JsonDB and date-formatting cases. Exceptions are flattened to ERROR, so the suite does not establish exact error classes.
