## What this file does

Hash an input value or the contents of a file.

## Follow the logic

1. If file is present, resolve it and reject a nonexistent path before reading bytes. This branch takes priority over data.
2. Otherwise stringify a JSON object/array directly or read the string parameter. Only a lowercase 0x prefix selects raw HEX; other text is encoded with MiniString.
3. Read type with default sha3, then select SHA2 or SHA3 exactly; reject other spellings.
4. Return file name/path/size or input/decoded bytes, followed by type and hash.

## How the translation is approached

C++ reuses MiniFile, MiniString, MiniData and Crypto. It follows the same file priority and input interpretation. Filesystem error details and time-of-check/file-size races remain beyond the finite fixture.

## What the tests tell us

The driver tests objects, arrays, Unicode text, 0x versus 0X, invalid hash kinds, files of 0/1/256/65536 bytes, a directory and an absent path. File cases include data:"ignored" to exercise precedence.

The actual [command driver](../../../../../../../../tools/command_differential.py) creates the inputs; [CommandOracle.java](../../../../../../../../support/CommandOracle.java) runs the pinned Java commands and [command.cpp](../../../../../../../../support/command.cpp) runs the native commands. The oracle uses a synthetic wallet address cache, not durable wallet storage. CommandException messages are compared separately, while other exceptions become ERROR. The existing [normal report](../../../../../../../../build/command-differential-results.json) records 12,289 cases passed, zero failures. This is a snapshot of the whole suite, not a new run or this command’s dedicated case count. Random outputs use per-runtime property checks rather than equality between independently generated bytes.
