## What this file does

Provide a process-global advisory transaction-building lock.

## Follow the logic

1. lockFunction synchronizes access: enabling succeeds only when not already locked; disabling clears the flag and returns true.
2. getLock retries every100ms. Its counter is increased after each sleep; a nonzero timeout fails only when counter>timeout. Timeout0 waits indefinitely.
3. runCommand reads action, timeout and unlockdelay before branching. lock returns success plus locked:true even when acquisition failed; list reports the actual global flag.
4. unlock waits for unlockdelay before clearing the lock, despite help text suggesting an after-unlock delay. A negative delay fails before unlocking.

## How the translation is approached

C++ combines a mutex for lockFunction with an atomic observable flag, explicit counter wraparound and bounded sleep chunks for large delays. Sleep now uses NativeThread interruption; the source timeout loop and lock mutation order are retained. Arbitrary concurrent caller behavior remains incompletely verified.

## What the tests tell us

The driver performs lock/list/retry/unlock sequences with short and negative timeouts, a100ms boundary, negative/positive unlock delays and malformed values for every parameter. Calls share process-global lock state. This is not a comprehensive fairness/concurrent stress proof.

The actual [command driver](../../../../../../../../tools/command_differential.py) creates the inputs; [CommandOracle.java](../../../../../../../../support/CommandOracle.java) runs the pinned Java commands and [command.cpp](../../../../../../../../support/command.cpp) runs the native commands. The oracle uses a synthetic wallet address cache, not durable wallet storage. CommandException messages are compared separately, while other exceptions become ERROR. The existing [normal report](../../../../../../../../build/command-differential-results.json) records 12,289 cases passed, zero failures. This is a snapshot of the whole suite, not a new run or this command’s dedicated case count. Random outputs use per-runtime property checks rather than equality between independently generated bytes.
