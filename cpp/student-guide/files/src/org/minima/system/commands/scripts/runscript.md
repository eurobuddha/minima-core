## What this file does

Build a supplied test context, execute a KISS script and report its addresses and execution state.

## Follow the logic

1. Read script plus optional state, previous state, globals, signature-key list and extra scripts. Build a transaction/witness by converting state ports, values, keys and serialized script proofs in source order.
2. Construct Contract and set @SCRIPT. If the original globals object contains uppercase @BLOCK and @CREATED but not @COINAGE, compute and insert their difference into that same globals object.
3. Uppercase global names when installing their Values, then run Contract. Later supplied globals can overwrite @SCRIPT.
4. Return original and cleaned script/address pairs, trace, variables and parse/monotonic/success flags.

## How the translation is approached

C++ reuses JSON, JavaInteger parsing, StateVariable, ScriptProof and Contract. Shared globals retain the visible @COINAGE mutation. Some context null checks and accessor ordering differ from Java, so the current normalized suite cannot certify every partial failure effect.

## What the tests tell us

The driver supplies valid/invalid scripts, matching/differing state, explicit and derived globals, key lists and MAST proofs generated by mmrcreate. It varies context JSON types and Unicode/overflow port strings and tests uppercase versus lowercase globals.

The actual [command driver](../../../../../../../../tools/command_differential.py) creates the inputs; [CommandOracle.java](../../../../../../../../support/CommandOracle.java) runs the pinned Java commands and [command.cpp](../../../../../../../../support/command.cpp) runs the native commands. The oracle uses a synthetic wallet address cache, not durable wallet storage. CommandException messages are compared separately, while other exceptions become ERROR. The existing [normal report](../../../../../../../../build/command-differential-results.json) records 12,289 cases passed, zero failures. This is a snapshot of the whole suite, not a new run or this command’s dedicated case count. Random outputs use per-runtime property checks rather than equality between independently generated bytes.
