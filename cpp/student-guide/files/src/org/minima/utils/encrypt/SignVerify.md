## Purpose

SignVerify creates and checks RSA signatures over message bytes using SHA256withRSA. Signing is separate from the RSA encryption helpers: a signature authenticates the bytes under a public key rather than hiding them.

## Follow the algorithm

1. sign decodes a PKCS#8 RSA private key, obtains the named Signature algorithm, initializes it with the private key and secure random source, updates it with all message bytes, and returns signature.sign().
2. verify decodes the public-key container, initializes verification, updates with the same message bytes, and calls verify on the supplied signature. False means the signature does not verify; invalid keys or malformed signature inputs can throw instead.
3. The main routine generates a key pair, signs random data, and prints a verification result. It is a demonstration; automated evidence comes from the separate fixtures.

## How the C++ translation works

The native implementation uses the reused GenerateKey decoders and OpenSSL EVP_DigestSign/Verify with SHA-256 and RSA. It checks signature byte length against the RSA key size before verification, returns false for a normal verification mismatch, and throws for provider errors. RAII frees digest contexts.

## Understanding the tests

The utility driver signs messages from length 0 through 2048 with key pairs generated by both languages and compares exact signature bytes for this deterministic algorithm. Derived verification cases include the original signature, truncation, an extra byte, final-byte corruption, and the original signature against a modified message. Comparing both returned booleans and ERROR distinguishes some malformed inputs from ordinary nonmatches.

## Limits and a useful next test

No assertion here proves all DER key acceptance rules or exact SignatureException categories. The driver’s deterministic comparison is specific to this algorithm and must not be generalized to every signature scheme. Key generation remains randomized even when signing the same bytes with one fixed key is deterministic.
