## What this file does

Hold unevaluated function arguments and supply the registry/validation rules shared by all 53 built-ins.

## Follow the logic

1. Normalize the constructor name and begin with an empty expression list. addParameter retains expressions for later evaluation.
2. getParameter rejects an index beyond the current count; checks for exact or minimum arity have distinct errors. Type checks use a bitmask, so a caller can accept HEX or STRING.
3. Parser-time checkParamNumberCorrect emits MinimaParseException. Runtime checks emit ExecutionException; preserving that separation matters.
4. getFunction searches the static prototype list and asks the match for a fresh function object, preventing arguments from one call contaminating another.

## How the translation is approached

C++ uses shared expression pointers and a function-static vector of prototypes. Its upper helper handles ASCII; Java constructor normalization is broader and locale-sensitive. These public-name edge cases remain outside complete parity.

## What the tests tell us

Every built-in in the driver is evaluated through the parser/registry. Missing/excess parameters, unknown names and incorrect types exercise the shared checks. MIN/MAX and GET/EXISTS require minimum counts, while most other functions require exact counts. No isolated arbitrary registry-mutation test is claimed.

The [KISS execution driver](../../../../../../../tools/kissvm_differential.py), [Java oracle](../../../../../../../support/KissVMOracle.java) and [native harness](../../../../../../../support/kissvm.cpp) compare actual execution, state, instruction counts and selected traces. See [the test-method lesson](../../../../../../evidence/kiss-builtins.md) for fixture construction and normalization limits. The existing normal report records 4,471 comparisons passed and zero failures; this is not a fresh run or a per-class test count.

## New mapped-test evidence

The mapped MinimaFunctionTests now checks 11 executed source assertions: known/unknown lookup, fresh helper metadata, shared expression identity, parameter count and the typed missing-index failure. The original two Java methods pass unchanged in both builds. Negative indexes, Unicode name normalization and arbitrary registry mutation remain outside that test. See [the detailed test lesson](../../../../../test/org/minima/tests/kissvm/functions/MinimaFunctionTests.md). All nine selected regression suites pass in normal and sanitizer builds.
