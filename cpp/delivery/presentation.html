The runnable system

Example: Java substring behavior

Address's demonstration forms five groups from a Base32 number. It skips characters between groups. A short encoding raises an exception before output. The C++ port explicitly retains those ranges and that failure boundary.

MinimaCoreC++

Current limits

456 mapped counterparts exist. One external JNI file is missing. Twelve audited source entry points remain absent, and full API/runtime parity remains unverified. The executable currently targets macOS 26+ on Apple Silicon.

Student work

Each lesson connects source intent, native logic and validation. Students can reproduce one test, explain its invariant, propose a counterexample and add a cross-language case. A useful lesson states what its tests do not prove.
